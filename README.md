# Piccola Italiano 🇮🇹

**意大利语学习 PWA · v0.15.0**

[打开应用](https://gewuerzei.github.io/piccola-italiano/) · [源码仓库](https://github.com/Gewuerzei/piccola-italiano)

一款完全独立于 Cassola 餐馆生产系统的 **local-first** 意大利语学习应用。首页跟随 Piccola 一次学一句；也可自由进入生活会话、词源考古、文字谜题、驾考术语与城邦文书游戏。

## 产品主线

每天打开即可继续：短讲解 → 一题一题练 → 反馈 → 后续回顾。课程增加时保持同一操作流程。例句和答后表达可手动使用系统意大利语朗读；这不是听力测评。

建设顺序固定为：课程与续做底座 → 一个完整的听辨/情境表达流程 → 丰富不同语境和延迟回顾 → 高阶与语言探索。具体范围和完成标准见 [PROJECT_PLAN.md](PROJECT_PLAN.md)。

## 学习模式

| 模块 | 当前内容 | 用途 |
| --- | --- | --- |
| 自动学习 | 27 节主线微课、324 道原创题；每轮 8 题，逐题反馈、提示和本机续做 | 选择 → 填空 → 受限短句改写，按本轮表现调整支撑 |
| 薄弱点混合复习 | 从已练课程中选八道题，优先重练最近卡住的学习点 | 来源清楚、可续做；零散复习不标整课完成 |
| 完整课程路线 | 40 个稳定单元、先修关系与目标；27 个可学、13 个待编写 | 先固定教材结构，再逐批补内容 |
| 知识库与复习 | 关联词汇、语法、例句及场景；本机间隔复习 | 建立可重复使用的语言知识 |
| 互动冒险 | 生活场景分支、意大利语会话和自我练习 | 从识别正确表达走向自己造句 |
| 🧪 迁移练习 | 六道有解释的语言迁移题；可跳过、不计分、不改进度 | 识别音变规律、语法差异与假朋友 |
| 🌉 语言桥梁 | 拉丁语、意大利语、西班牙语、法语的三组同源词与一组语法功能比较；可用时播放现代语音 | 解释音变及不可机械套用的结构 |
| 🧭 个人学习路线 | 结合课程先修、实用价值及最近测评证据生成五条可解释建议 | 不改变成绩或复习计划，非官方能力诊断 |
| 🧭 书记官能力定位 | 可选12道变化难度的小测 + 1项写作自评；阅读、语法、词汇分开汇报 | 帮你定位复习方向，不等于CEFR能力证书，不推断听力/口语 |
| 🗺️ 知识地图 | 5层、25个只读知识节点及先修关系；拉丁语声变示例和IPA、部分现代语音按钮 | 把既有知识串联成学习结构；目前不是能力评级或自适应推荐 |
| Italiano Vivo | 12回合NPC实战对话、6个绕词挑战、6道语法侦探、6道词根反推 | 30个离线表达与推理关卡，独立首次通过记录；自由表达为参考答案自评 |
| 词源考古 | 36份有词典来源链接的词源档案 | 追查拉丁语、希腊语、Veneto 等语源 |
| 词源谜案 | 9宗连续谜题，另有12关词根推理 | 输入词形、排序线索、验证推断 |
| 中古城邦文书院 | 6宗虚构案件：24份物证、18段证词、12道条款解码 | 在调查与裁决中理解意大利语 |
| Operazione Patente B | 14天复习计划、示例题与题库导入入口 | 驾考术语训练及模拟练习 |

**关于考试题库：** 当前仓库没有内置完整、经校验的意大利官方理论考试题库。原有40道驾考示例题是自编练习，不应标注为官方真题。导入器可以读取带有明确题干和答案字段的受支持文件；MIT 原始 TXT 尚未完成真实文件格式验证，不能声称官方题库已经成功导入。模拟考试也不应被宣传为已经复现官方抽题算法。

**关于历史内容：** 中古城邦剧情是虚构设定，题目中的意大利语为面向现代学习者的教学文本，不是声称出土的中世纪原始文书。词源档案为自行编写的解释，附有外部词典出处，不复制外部词典全文。

## 如何使用

1. 用 iPhone Safari 打开上方应用链接。可用“分享 → 添加到主屏幕”安装。
2. 首页点「开始自动学习」即可看短讲解、逐题练习；做到一半可以暂停，下次「继续学习」接着做。每轮 8 题，提示后的答案算辅助练习；填空和指定改写按有限答案表核对，不是自由回答 AI 批改。
3. 点「查看课程路线」查看 40 单元骨架；L1–L3 的 27 个单元已提供起始自动课。展开「自由探索」可访问原有模块。知识地图仍是 25 节点的关联网络，不表示个人水平。
4. 自由探索可进入「书记官能力定位」，每个方向4道小题；随时暂停或跳题，最后可以对照范例自评写作。报告不是官方语言等级，也不作AI自动评阅。
5. 城邦文书院需调查物证、询问证人、完成语言解码，再选择一次正式裁决。Italiano Vivo 在首页或冒险中心进入；自由回答需要对照范例自行评估，不是AI对话或AI批改。
6. 在“我的”中定期 **导出 JSON 备份**。删除网页数据或卸载 PWA 可能丢失本地学习记录。

## 数据与技术

- 纯前端静态站点，GitHub Pages 部署，离线资源由 `sw.js` 缓存。
- 学习记录默认存在设备 IndexedDB：`piccola-italiano` / store `data` / key `state`，`schemaVersion=1`；不可用时降级至 localStorage。
- 无账号登录、云端学习记录同步，也**不会**通过 GitHub 自动上传用户本地数据。
- 可选本地 `state.autoTutor` 保存自动课当前题、反馈、提示、草稿、最近 60 轮记录，以及每节课的最近完成记录。备份导入可恢复有效续做状态，但不会覆盖本机正在进行的自动课。
- 可选本地 `state.placement` 保存测评续做和最近8轮结果；写作原文不保存，备份合并已完成测评但不覆盖本机未完答卷。
- JSON 备份支持非破坏性合并。**严禁通过清空 IndexedDB/localStorage 来处理升级或故障。**
- 公共仓库不存放私人学习备份、授权令牌、密码或用户数据。
- 语音播放依赖设备本地语音服务与对应语言的可用voice；知识地图的拉丁语仅显示重建IPA，不提供冒充真实古罗马录音的按钮。iPhone PWA仍需设备测试。
